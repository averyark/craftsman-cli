# Docs index

Every published page of the Craftsman docs, in the sidebar's order. Generated by `scripts/docs-index.mjs` in the console's repository: do not edit.

Read a page with `read_doc` from `craftsman mcp`, passing its address. Never fetch the site. `docs/README.md` says how.

## Overview

What LOCS is, the systems it is made of, and how they fit together.

- `/docs/overview/locs-overview` **What LOCS is.** Craftsman LOCS is a set of systems you use to ship, run, inspect and fix a live Roblox game.
- `/docs/overview/how-locs-works` **How LOCS works.** LOCS is three parts in your repository and one console, with your data kept in Roblox and your servers able to run without Craftsman.
- `/docs/overview/find-your-way` **Find your way around.** The console's pages, its top bar, the place group menu and the sidebar.
- `/docs/overview/read-the-overview` **Read the Overview.** See what needs you, how your project is doing and what changed lately, on the console's first page.

## Getting started

Install the CLI, sign in, set a game up, make a feature and ship your first release.

- `/docs/getting-started/what-is-project-control` **Start here.** Five steps take a Roblox game from an empty repository to a feature you can switch off from the console.
- `/docs/getting-started/create-your-account` **Create your account.** Open your sign-up link, confirm your Discord account and save a passkey.
- `/docs/getting-started/install-the-cli` **1. Install the CLI.** Install the craftsman command and Rojo with Rokit, pinned in your repository so everyone runs the same version.
- `/docs/getting-started/sign-in-from-the-terminal` **2. Sign in.** Sign the CLI in with your passkey in the console, check who it acts as, and choose which console it talks to.
- `/docs/getting-started/set-up-a-project` **3. Set up a project.** Run craftsman init to install Craftsman's packages and write the files your game needs, then serve it to Studio.
- `/docs/getting-started/make-your-first-feature` **4. Make your first feature.** Add a feature with one config, read the config in your code, and try it in Studio.
- `/docs/getting-started/publish-your-first-release` **5. Publish and release.** Check your declaration with the console, build a release on GitHub, deploy it, then change your feature from the console.

### Craftsman Kit

- `/docs/craftsman-kit/kit-overview` **What the kit is.** Which module to use for each job, how to require it, and how to boot it.
- `/docs/craftsman-kit/kit-settings` **Kit settings.** The settings of the kit in craftsman.toml, and Config.Configure at run time.
- `/docs/craftsman-kit/kit-entity` **Entity.** A wrapper around a character, with rig references, a Keeper and signals.
- `/docs/craftsman-kit/kit-tag` **Tag.** Status effects and flags on instances, which stack, expire and replicate.
- `/docs/craftsman-kit/kit-state-machine` **State machines.** Nested states, with optional replication from the server to clients.
- `/docs/craftsman-kit/kit-pathfind` **Pathfind.** Move an NPC along a path, chase a target, and recover when stuck.
- `/docs/craftsman-kit/kit-queue` **Queue.** Run async jobs one at a time, with retries, timeouts and deduplication.
- `/docs/craftsman-kit/kit-debounce-and-concurrency` **Debounce and Concurrency.** Debounce or throttle a function, and lock or cool down per key.
- `/docs/craftsman-kit/kit-tween-and-spring` **Tweens and springs.** Named animation templates with TweenUtil, and physics with Spring.
- `/docs/craftsman-kit/kit-animation` **AnimationUtil.** Register animations by name, and play them on a rig.
- `/docs/craftsman-kit/kit-sound` **SoundUtil.** Sound groups, a registry, one shots and a player for each object.
- `/docs/craftsman-kit/kit-input` **InputUtil.** Named actions, rebinding and device type.
- `/docs/craftsman-kit/kit-touch` **TouchUtil.** Mobile buttons that fire InputUtil actions, with player layouts.
- `/docs/craftsman-kit/kit-interface` **InterfaceUtil.** Scale UI to any screen by driving a UIScale.
- `/docs/craftsman-kit/kit-world` **WorldUtil.** Casts, ground checks, overlaps, nearest and screen projection.
- `/docs/craftsman-kit/kit-math` **MathUtil.** Interpolation, angles, curves, random picks and number formats.
- `/docs/craftsman-kit/kit-string-and-table` **StringUtil and TableUtil.** String and table helpers, and which ones change their input.
- `/docs/craftsman-kit/kit-print-and-inspect` **PrintUtil and Inspect.** Print tables and render any value as text.
