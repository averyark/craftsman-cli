# craftsman

An agent skill for Roblox games built on Craftsman and Project Control.

```bash
npx skills add averyark/craftsman-cli
```

Works with Claude Code, Cursor, Copilot, Gemini and anything else that reads a `SKILL.md`.

## What it is for

It is not the documentation. A full copy of that is in `references/docs-bundle.md`. The skill carries what a reference page cannot: which part of the product to reach for, what fails silently, what only a person can do, what to stop and ask about, and how an AI tends to get Craftsman wrong. Its job is to make an agent use the whole product instead of writing by hand what the console then cannot see.

## Updating the bundle

`references/docs-bundle.md` is generated by `scripts/docs-bundle.mjs` in the console's repository, from the published docs. After a docs change, run it again.

## Updating the skill

The versions in `SKILL.md`'s `metadata` and its last section name what it was checked against. After a release, check the references against the source, then move them.

## Not for Craftsman itself

Working on Control, the kit or Lifecycle is a different job. `SKILL.md` checks for that and stops. Ledger has its own skill: `npx skills add XoifaiI/Ledger`.
